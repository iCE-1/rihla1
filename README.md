# الرحلة العلمية — خريطة الملفات

التطبيق يرسم واجهته بالجافاسكربت داخل `<div id="app">`، لذلك قوالب الواجهة (HTML) موجودة داخل ملفات `js/`، وملفات `css/` للتنسيق فقط.
ترتيب تحميل الملفات في `index.html` مهم ويجب ألا يتغيّر، و`99-main.js` يبقى آخر ملف.

## ملفات JS

| الملف | محتواه |
|---|---|
| `01-core.js` | الثوابت والحالة العامة، الملاحظات، الثيم، الإعداد وتسجيل الدخول، `init`، `renderApp`، التبويبات والتمرير |
| `02-helpers.js` | الأيقونات `ic`، التواريخ، نشاط الكتب `bookTimeHtml`، وضع القراءة، الحفظ التلقائي للمسودة |
| `03-books-daily.js` | الكتب (ذاكرة مؤقتة)، الكتب الجارية، `showToast`، تسجيل التقدم، الواجهة اليومية |
| `04-path-tree.js` | صفحة «الطريق»: شجرة العلوم، السحب والإفلات، إضافة/تعديل/حذف العلوم والكتب |
| `05-focus.js` | التركيز: بومودورو، المؤقت الحر، ساعة التوقف، المنبّه، تسجيل الجلسات |
| `06-entries.js` | القيود: إضافة/تعديل/حذف، السجل الزمني، الوسوم، ملخص الشهر |
| `07-goal-vacation.js` | جلب الصفوف، الهدف اليومي، أيام الإجازة |
| `08-account.js` | الحساب: الملف الشخصي، التقويم، الإنجازات، الأوسمة، ملخص السنة والخط الزمني |
| `09-stats.js` | الإحصائيات: الرسوم SVG، المعدل الأسبوعي وتوقع إنهاء الكتب |
| `10-backup.js` | النسخ الاحتياطي والاستيراد، `formatDate`، `escapeHtml` |
| `11-problem-tree.js` | تشجير المسائل |
| `99-main.js` | تشغيل `init()` |

## ملفات CSS

| الملف | محتواه |
|---|---|
| `base.css` | المتغيرات والثيمات، التخطيط، النماذج، السجل، التبويبات، الإحصائيات والرسوم |
| `path-tree.css` | شجرة «الطريق» وحركتها |
| `polish.css` | تحسينات التجربة وتوحيد الخطوط والألوان والتأثيرات |
| `account.css` | صفحة الحساب |
| `notes.css` | خانات الملاحظات |
| `problem-tree.css` | تشجير المسائل |

## ماذا ترسل عند طلب تعديل؟

| المطلوب | الملفات |
|---|---|
| إحصائيات، معدل، توقع الإنهاء، الرسوم | `09-stats.js` (+ `base.css` للتنسيق) |
| الحساب والأوسمة والتقويم | `08-account.js` + `account.css` |
| التركيز والمؤقت | `05-focus.js` |
| الطريق وشجرة العلوم | `04-path-tree.js` + `path-tree.css` |
| السجل والقيود والوسوم | `06-entries.js` |
| الهدف اليومي والإجازات | `07-goal-vacation.js` |
| تشجير المسائل | `11-problem-tree.js` + `problem-tree.css` |
| تغيير الألوان أو الخطوط عمومًا | `base.css` + `polish.css` |
| الدخول والإعداد والتبويبات | `01-core.js` |

إذا لم تعرف أين المشكلة فاذكر اسم الصفحة أو الميزة وسأحدد الملف.

## بعد كل تعديل

غيّر رقم `?v=1` في `index.html` إلى رقم أعلى للملف المعدَّل (مثل `?v=2`) حتى لا يعرض المتصفح النسخة القديمة المخزّنة.
